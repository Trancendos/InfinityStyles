🎯 **What:**
Added unit tests for the `cn` utility function in `lib/utils.ts` to ensure it correctly merges tailwind classes using `clsx` and `tailwind-merge`.

📊 **Coverage:**
The new tests cover the following scenarios:
- Merging simple class names
- Handling tailwind class overrides properly (e.g. `p-4 p-2` -> `p-2`)
- Conditionally applying classes
- Handling array and object inputs
- Dealing with complex tailwind class conflicts

✨ **Result:**
Test coverage and reliability of the tailwind class merge utility have been significantly improved. We now have a test safety net that ensures the `cn` utility works as intended and won't regress during refactoring.
